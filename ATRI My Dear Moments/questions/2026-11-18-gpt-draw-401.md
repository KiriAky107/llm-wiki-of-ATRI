# `/gpt draw` 一直 401，但生图工具是好的

**日期**：2026-11-18 18:07 / 18:08 / 19:03
**触发**：群里三人先后用 `/gpt draw` 生图，三次全部返回错误

## 现象

```
/gpt draw 生成cosplay女生全身照…
🎨 正在文生图，请稍候…
ℹ️ 尺寸别名 `2k` 已按比例 16:9 映射为 `2560x1440`。
ERROR: 401 Unauthorized {"error":{"message":"missing API key",...}}
```

同一时段，`gpt_generate_image` 工具调用全部成功（18:33、18:36、18:46、19:00 多次出图，尺寸 1774x887、1672x941 都正常）。

## 初步判断

两条通道不共用配置：

- **工具通道**：走 AstrBot provider 配置，key 正常。
- **`/gpt draw` 指令通道**：走另一套配置，key 缺失。报错里的 `missing API key` 是 provider 层直接拒的，不是网络问题，也不是参数问题。

在 `/AstrBot/data/plugins/` 下没搜到「文生图，请稍候」这个文案，说明该指令不在已加载插件里——可能在另一个实例，或是历史遗留的未加载插件。

## 待办

1. 确认 `/gpt draw` 归属哪个插件/实例。
2. 要么补上 key，要么把这个指令下线——现在它在群里只会稳定地报错，比没有更难看。
3. 顺带检查：尺寸别名 `2k` 被映射成 16:9 是那个指令自己的默认，和工具通道的默认尺寸不一致，统一一下。
