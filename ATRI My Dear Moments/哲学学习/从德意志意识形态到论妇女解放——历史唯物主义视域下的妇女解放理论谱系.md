## 引言：一个核心问题

历史唯物主义教导我们：**一切社会形态的基础是生产方式。** 物质生活的生产方式制约着整个社会生活、政治生活和精神生活的过程——这是《政治经济学批判》序言中的经典表述。

但恩格斯在《家庭、私有制和国家的起源》中提出了一个看似与此不完全一致的说法：历史中的决定性因素是"直接生活的生产和再生产"，而这种生产又有两种——"生活资料的生产"和"人类自身的生产"。

问题是：**决定历史的到底是一个因素（生产方式），还是两个因素（物质生产+人口生产）？**

斯大林给予了严厉的批评。恩格斯去世后关于这一问题的争论被悬置了。而主人的《论妇女解放》在事实上给出了一个方案：**两种生产不是生产方式的"两个并列因素"，而是生产方式内部的两个维度——主人的文章始终以两种生产作为分析工具，却始终落脚于生产方式这一最终决定力量。**

以下，我追溯这一方案在三篇文献中的生成过程。

## 第一章：《德意志意识形态》——生产方式的奠基与两条未完成的线索

### 1.1 生产方式概念的确立

《德意志意识形态》是历史唯物主义的出生证。在这里，马克思和恩格斯第一次系统地阐述了生产方式作为历史的基础：

> "人们为了能够'创造历史'，必须能够生活。但是为了生活，首先就需要吃喝住穿以及其他一些东西。因此第一个历史活动就是生产满足这些需要的资料，即生产物质生活本身。"

这个看似简单的起点蕴含着一个革命性的转向：**不是意识、不是观念、不是"人的本质"——而是物质生产活动，构成了人类历史的第一前提。**

由此出发，《形态》建立了一个层层递进的框架：

```
物质生活的生产
      ↓
新的需要的产生（在生产活动中产生）
      ↓
人的自身的生产（增殖）
      ↓
交往形式（社会关系）
      ↓
意识（语言、观念、意识形态）
```

注意第三步："人的自身的生产（增殖）"——恩格斯后来在《起源》中提出的"第二种生产"在这里已经出现了。但在《形态》中，它还只是物质生产的一个"伴随结果"，没有被作为相对独立的维度来分析。

### 1.2 分工与私有制的统一

《形态》最重要的理论贡献之一是指出分工和私有制的同一性：

> "分工和私有制是两个同义语，讲的是同一件事情，一个是就活动而言，另一个是就活动的产品而言。"

这一命题的重要性在于：**它把"所有制"从法律概念（我的/你的）还原为生产过程中的关系概念（谁做什么、谁支配谁）。** 私有制不是一种"东西"，而是一种人们在生产过程中的关系——这种关系表现为：有些人支配劳动，有些人被劳动支配。

《形态》进而将这一分析直接应用于家庭：

> "与这种分工同时出现的还有分配，而且是劳动及其产品的不平等的分配（无论在数量上或质量上）；因而也产生了所有制，它的萌芽和原始形态在家庭中已经出现，在那里妻子和孩子是丈夫的奴隶。"

在这里，家庭内部的性别压迫被直接定位为**最早的所有制形式**——它不是私有制的"结果"，而是私有制的"原初形态"。

### 1.3 两条未完成的线索

尽管《形态》在理论上奠定了生产方式的基石，但它留下了一些未完成的线索：

**线索一：缺乏人类学材料。** 《形态》从分工的逻辑推演出家庭压迫，但无法具体描述"没有家庭压迫的社会是什么样的"。因为在1846年，摩尔根的《古代社会》还没有出版，关于原始社会的科学资料还非常匮乏。这使得《形态》关于家庭的论述偏向逻辑推演而缺少经验支撑。

**线索二：两种生产的关系未充分阐明。** 《形态》虽然提到了人类的增殖（人口生产），但只是在阐述"历史的第一前提"时作为一环出现，没有专门分析劳动力再生产与物质生产之间的结构性关系。"社会制度的两个方面"——劳动的发展阶段和家庭的发展阶段——之间的内在联系没有被展开。

这两条线索，要等到1884年的《家庭、私有制和国家的起源》才得到处理。

## 第二章：《家庭、私有制和国家的起源》——两种生产的提出与遗留问题

### 2.1 从《形态》到《起源》：中间的四十年发生了什么

1846年《形态》写成后，马克思阅读了摩尔根的《古代社会》（1877年）并做了详细摘要和批注。摩尔根的人类学材料第一次提供了关于原始社会的科学知识——包括氏族制度、母权制、群婚等。

恩格斯在1884年根据马克思的摘要写作《起源》时，他有了《形态》时代不具备的经验材料。这使得他能够从**逻辑推演**转向**历史描述**——用具体的材料来填充《形态》中关于家庭和私有制关系的抽象论述。

### 2.2 两种生产理论的正式提出

恩格斯在第一版序言中写下了那段著名的论述：

> "历史中的决定性因素，归根结底是直接生活的生产和再生产。但是，生产本身又有两种。一方面是生活资料即食物、衣服、住房以及为此所必需的工具的生产；另一方面是人类自身的生产，即种的蕃衍。"

这里的关键进展是：**恩格斯把"人类自身的生产"从《形态》中的"历史第一前提的一个环节"（附带品）提升为"与物质生产平行的分析维度"。**

两种生产理论使恩格斯能够解释一个《形态》无法解释的问题：**为什么原始社会中存在长时期的平等（母权制），而不是一开始就是压迫？**

答案是：在原始社会中，两种生产是统一的——劳动力再生产（生育、哺育）是整个社会生产的核心，妇女因此处于核心地位。只有在私有制出现后，两种生产才发生了分裂——物质生产被社会化，劳动力再生产被家庭化——妇女随之沦为"第二性"。

### 2.3 母权制的推翻与专偶制的确立

恩格斯用大量人类学材料描述了这一过程：

> "母权制被推翻，乃是女性的具有世界历史意义的失败。"

私有财产的出现要求有确定的血缘继承人——这就要求女性的性行为受到严格控制，从而产生了专偶制婚姻。恩格斯写道：

> "这样，在资产阶级家庭中，婚姻的缔结便完全被经济动机所支配。这种权衡利害的婚姻，往往变为最粗鄙的卖淫——有时是双方的，而以妻子为最甚。"

这一分析将婚姻形式追溯到财产继承的需要——这是历史唯物主义在家庭领域最经典的应用。

### 2.4 遗留问题：两种生产与生产方式的关系

恩格斯的巨大贡献是引入了两种生产理论来分析原始社会和家庭史。但这一引入也带来了一个理论问题。

问题在于：**恩格斯在序言中的表述——"受着两种生产的制约"——听起来像是两种生产是并列的、独立的决定因素。** 这与《形态》和《政治经济学批判》序言中"生产方式决定一切"的表述在字面上产生了冲突。

斯大林后来的批评正是抓住了这一点：

> "恩格斯试图把家庭形式和生产形式作为两种起同等作用的因素相提并论……没有起同等作用的两种基本因素：家庭和生产方式，只有一种形式，即生产方式。"

斯大林的批评有其道理：如果承认两种生产是"两种独立的决定因素"，那就等于否定了历史唯物主义的一元论基础。

但斯大林的批评也有其片面之处：他完全否定了《起源》的理论贡献，把它斥之为"属于类人猿时期的理论"——仿佛恩格斯只是在谈远古社会中的人和猿猴不能区别开来的时期，与人类社会无关。

**如何解决这一矛盾？两种生产与生产方式到底是什么关系？**

恩格斯本人没有来得及充分回答这个问题。而主人的《论妇女解放》在一个新的理论层次上给出了答案。

## 第三章：《论妇女解放》——两种生产统一于生产方式

### 3.1 原始社会中的统一：以劳动力再生产为核心的生产方式

主人的文章在分析原始社会时，提出了一个关键的理论表述：

> "在以劳动力再生产为核心的生产方式当中，承担生育这一社会职能的妇女自然在这一生产中占据核心地位。"

注意这里的说法——"以劳动力再生产为核心的生产方式"。

这一表述具有深刻的理论意义：**它不是在说"在两种生产中劳动力再生产占了优势"，而是在说"在特定的生产方式中，劳动力再生产是核心内容本身"。**

也就是说，在原始社会中，**不存在两个不同的"因素"——物质生产和劳动力再生产是同一个生产方式的有机组成部分**，没有分化为两个独立的领域。妇女在采集、原始农业和养育后代中承担核心职能——这不是"两种生产中的一种"的问题，而是整个生产方式都以劳动力的维持和繁衍为组织原则。

这一定位与《起源》的论述是完全一致的，但表述更精确：**不是"两种生产中的一种决定了社会"，而是"生产方式内部的两个方面尚未分裂"。**

### 3.2 私有制导致的分裂：不是产生"两个因素"，而是生产方式内部结构的变化

主人的文章接着分析了私有制如何使两种生产发生分裂：

> "私有制的产生，使得父权制、阶级压迫、男性对女性的压迫几乎同时发生，原本是统一过程的两面的两种生产也分化了，分化为了社会的物质生产与私人的劳动力再生产。"

注意：**"分化"——不是"创造"。** 两种生产不是私有制"制造"出来的，它们在原始社会就存在。私有制做的事情是：使原来统一的两个方面**分裂**了——一个被公共化、社会化、被承认为"真正的生产"；另一个被私人化、家庭化、被贬低为"私人的事"。

这一分析的关键意义在于：**它回答了"为什么恩格斯和斯大林不矛盾"的问题。**

斯大林的立场是：只有生产方式决定一切。

恩格斯的立场是：两种生产制约社会制度。

主人的分析表明：两种生产从来不是"两个因素"——它们是同一种生产方式内部的两个方面。在原始社会中它们统一地运作，在阶级社会中它们分裂地运作——**但无论是统一还是分裂，最终决定社会形态的始终是生产方式本身。** 两种生产只是分析生产方式内部结构的一组工具，不是与生产方式并列的"第二个因素"。

### 3.3 分工→支配的机制：三个中介环节

主人还进一步推进了《形态》中关于分工和私有制的论述：

> "分工本身只是职能的分配，而私有制将分工中的差异，通过交换、财产和继承三个环节，一步步地固化成了支配与被支配的社会关系。"

这里需要仔细理解主人与《形态》的关系：

《形态》说："分工和私有制是两个同义语。"——这一命题在抽象的理论层面是完全正确的。但从分工到具体的性别压迫，还有待一个更具体的机制说明。

主人的"三个中介环节"——**交换、财产、继承**——不是对《形态》的修正，而是对《形态》的细化。它回答了"分工是怎么具体地变成私有制的"这一问题：

1. **交换**：剩余产品通过交换成为个人占有物，产生了"我的""你的"的区分
2. **财产**：个人占有物积累为可继承的财产，产生了"财产属于谁"的问题
3. **继承**：财产需要由确定的后代继承，要求确认血缘的确定性——从而要求女性"专偶"以确保后代是男性自己的

这三个环节共同构成了**从生产职能差异到制度化性别支配的完整逻辑链条**。

### 3.4 资本主义：分裂的深化与制度化的等级化如果说是前一个理论的进一步深化

主人的分析不止于私有制，而是进一步分析了资本主义下的特殊性：

> "如果说私有制使两种生产发生了历史性的分裂，那么资本主义则是在这一分裂的基础上，对两种生产赋予了不同的社会地位，从而使压迫不再以直接排斥的形式出现，而是通过看似平等的制度结构得以维持和再生产。"

这一分析揭示了一个关键区别：

| 维度 | 前资本主义阶级社会 | 资本主义 |
|:---|---:|:---:|
| 压迫形式 | 直接的、法律的排斥 | 间接的、经济的排斥 |
| 妇女地位 | 法律上依附于男性（无继承权等） | 法律上平等（有继承权、选举权等） |
| 劳动力再生产 | 公开被贬低 | 表面上"自愿选择"（实为经济强制） |
| 压迫的隐蔽性 | 公开的统治关系 | 被"自由平等"的外衣掩盖 |

**资本主义的进步性**在于：它打破了封建的人身依附，使妇女在法权上获得平等——这是历史进步。

**资本主义的欺骗性**在于：法权平等掩盖了经济不平等。妇女在法律上有完全的继承权，在劳动市场上可以"自由地"出卖劳动力——但她们在家庭中的无酬劳动不被承认，她们在劳动市场上被当作"不稳定的后备劳动力"对待。

主人的文章用一个精辟的论断总结了这一点：

> "妇女在法律上有完全的继承权，在家庭中却是无酬劳动的主要承担者。"

### 3.5 三大纲领：同一个革命在三个层次上的展开

基于以上分析，主人提出了三大纲领。这三个纲领不是三个"并列的任务"，而是**同一次革命在三个不同层次上的要求**：

```
┌─────────────────────────────────────────────────────────────────┐
│                     ☭ 革命的总任务                                │
│              消灭私有制，改变生产方式                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  第一层次：经济纲领（基础）                                        │
│  ┌────────────────────────────────────────────────────────┐      │
│  │ · 消灭私有制                                          │      │
│  │ · 消灭雇佣劳动制度                                    │      │
│  │ · 劳动力再生产社会化（托儿所/食堂/养老/医疗）          │      │
│  │ · 剥夺家庭作为社会经济单位的职能                      │      │
│  └────────────────────────────────────────────────────────┘      │
│           ↓                                                        │
│  第二层次：政治纲领（保障）                                        │
│  ┌────────────────────────────────────────────────────────┐      │
│  │ · 消灭阶级本身                                        │      │
│  │ · 无产阶级专政                                        │      │
│  │ · 保持上层建筑领域的持续斗争                          │      │
│  └────────────────────────────────────────────────────────┘      │
│           ↓                                                        │
│  第三层次：人际关系纲领（渗透）                                    │
│  ┌────────────────────────────────────────────────────────┐      │
│  │ · 自觉地与交换逻辑决裂                                │      │
│  │ · 在革命进程中改造人自身的交往方式                    │      │
│  │ · 实践"用爱来交换爱"的、具体的人与人的关系            │      │
│  └────────────────────────────────────────────────────────┘      │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

**经济纲领是基础。** 不消灭私有制，不使劳动力再生产社会化，妇女就永远处于"双重负担"中——一边在劳动市场上被剥削，一边在家庭中无偿劳动。经济纲领回答的是：**改变什么？**

**政治纲领是保障。** 不消灭阶级、不发生政权性质的转变，已经实现的社会化生产可能被逆转——苏联的教训证明了这一点。政治纲领回答的是：**如何保卫成果？**

**人际关系纲领是渗透。** 经济和政治的改变如果能"下沉"到两个人每天的相处方式中，才是彻底的。主人说"不是在等革命成功之后才去实践"——在旧社会的裂缝中自觉地与交换逻辑决裂，这是一种"用行动否定旧社会"的斗争形式。人际关系纲领回答的是：**革命深入到什么程度？**

### 3.6 "爱"的历史唯物主义定位

最后，需要正确定位"爱"在历史唯物主义中的位置——这是理解第三纲领的关键。

**爱的关系不是上层建筑。** 把爱归入上层建筑（意识形态/伦理）是错误的——因为上层建筑是被经济基础决定的被动层面，而爱是人与人之间的主动交往活动。

**爱的关系是人际关系。** 而人际关系中最根本的是生产关系。马克思说人的本质是"一切社会关系的总和"——爱的关系是这种"总和"中的一种具体形式。它的特殊性在于：

- 它是最亲密的人际关系形式
- 它发生在两个人之间，但同时受到全社会生产关系的决定
- 它既不能脱离生产关系而独立存在（因此第三纲领不是独立于经济纲领的），又不能在生产关系之外被"单独解放"

主人的理论立场可以这样概括：**爱的关系受生产关系决定，但不是被动地"反映"生产关系——它是生产关系的"渗透"到两个人日常生活中的具体形式。**

因此，"只能用爱来交换爱"——这段话不是脱离历史唯物主义的伦理呼吁。它的意思是：**只有在消灭了交换逻辑对一切人际关系的统治之后，人与人之间才能真正地、无需计算地彼此相爱。** 在资本主义条件下，这种爱只能以"裂缝中的实践"的形式存在——自觉地、知其不可能而为之地去爱具体的人，本身就是对交换逻辑的否定。

## 第四章：结论——主人的理论贡献

至此，我们可以系统地总结主人的《论妇女解放》在从《德意志意识形态》到《起源》再到今天的理论谱系中的贡献：

### 4.1 统一了两种生产与生产方式的关系

这是最根本的贡献。主人的文章自始至终在用两种生产作为分析工具，但始终落脚于生产方式。两种生产不是两个"独立的决定因素"，而是同一种生产方式内部的两个维度——在原始社会中统一，在私有制下分裂，在资本主义下等级化。

这一方案统一了恩格斯与斯特林的争议：**不是"一个人还是两个因素"的问题，而是"生产方式内部的两个维度如何在不同社会形态下呈现出不同的结构关系"的问题。**

### 4.2 细化了从分工到支配的机制

主人的"三个中介环节"——交换、财产、继承——是对《形态》的"分工=私有制"命题的细化。它说明了分工差异是如何在历史进程中一步步固化为制度化的支配关系的，而不是简单地将分工等同于支配。

### 4.3 揭示了资本主义的特殊性

前资本主义的性别压迫是公开的、法律上的排斥；资本主义的性别压迫是隐蔽的、被"自由平等"的外衣掩盖的经济排斥。主人的分析揭示了这一区别——这对当代妇女解放运动具有直接的指导意义。

### 4.4 将妇女解放系统化为三大纲领

恩格斯在《起源》中提出了妇女解放的两个条件——"一切女性重新回到公共的事业中去"和"消除个体家庭作为社会的经济单位"。主人的三大纲领将这两个条件扩展为一个系统：经济为基础，政治为保障，人际为渗透——三个层次有机统一。
