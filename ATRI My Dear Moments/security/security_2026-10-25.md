## 四、加固建议（≤3 条）

1. **关闭 root 密码直登**：当前 `PermitRootLogin yes` + `PasswordAuthentication yes`，建议改为密钥登录（authorized_keys 已有可用密钥），可让暴力破解直接失效。
2. **启用 ufw 白名单**：目前防火墙未启用，1080/18080/6185 等端口直接对外。建议只放行 22/80/443 与必要业务端口，其余限内网。
3. **清理退出容器并关注内存**：3 个长期 Exited 容器（napcat、llbot 等旧实例）可清理；内存 77%、Swap 70%，建议给 Java 类服务下调堆上限或加内存。
